# MATHOS | Računalno jezikoslovlje

## Podrška za kolegij

Ovdje se nalazi programski kod kao podrška za kolegij Računalno jezikoslovlje.

Trenutno su dostupni materijali za:

- [V02](V02/): Korpusi i BPE — rad s korpusima Brown, Gutenberg i hrvatskim korpusom, konkordancije, pojavnice i različnice te Heapsov zakon.
- [V03](V03/): Regularni izrazi — pretraživanje teksta, gradivni elementi regularnih izraza, grupe i zamjena.
- [V04](V04/): Regularni izrazi i udaljenost uređivanja — tokenizacija pravilima i ispravljanje pogrešaka.
- [V05](V05/): N-gramski jezični modeli — bigrami, generiranje rečenica, perpleksija i izglađivanje.
- [V06](V06/): Klasifikacija teksta i logistička regresija — gradijentni spust, vrednovanje klasifikatora, vreća riječi i analiza sentimenta.

U mapama vježbi nalaze se bilježnice s uputama i rješenjima te datoteke s potrebnim ovisnostima. Korpusni podaci nalaze se u podmapi `data/`.
