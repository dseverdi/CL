# Korpus

Rečenice iz treebanka **UD Croatian SET** (Universal Dependencies).

* `hr_train.txt`, `hr_test.txt` — za V2: jedna rečenica po retku, tokeni odvojeni razmakom.
* `hr_train.tsv`, `hr_test.tsv` — iste rečenice s izvornim tekstom; stupci odvojeni tabulatorom:
  oznaka dokumenta, izvorna rečenica, tokeni (zlatni standard). Za vježbe iz regularnih izraza
  (tokenizacija pravilima, segmentacija rečenica).
