# Korpus

Rečenice iz treebanka **UD Croatian SET** (Universal Dependencies): hrvatske vijesti s portala SETimes.

* `hr_train.txt` — jedna rečenica po retku, riječi i interpunkcija odvojeni razmakom (kao u V2).
* `hr_vijesti.txt` — iste rečenice u izvornom obliku, jedna po retku (interpunkcija uz riječ, datumi i iznosi kako su napisani).
